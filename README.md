# Qazo Namoz

Офлайн-трекер каза (упущенных) намозов. React + Vite, дизайн-система из BuildFlow
(«Botanical Earth», шрифты Inter/Unbounded, темы). Собирается в Android APK через
Capacitor. Данные хранятся локально на устройстве (localStorage) — без аккаунтов
и интернета.

## Возможности
- Дашборд: сколько каза осталось всего и по каждому намозу (Бомдод/Пешин/Аср/
  Шом/Хуфтон + Витр), сколько уже прочитано.
- «Қўшиш» — отметить конкретный упущенный намоз с датой; опция «Каср» (в пути).
- «Ўқидим» — прочитанный намоз уходит с дашборда в журнал (можно отменить).
- Калькулятор: считает каза по датам (балоғат → начало намаза) для 5 намозов + Витр.
- 8 тем (переключатель — иконка палитры в шапке).

## Разработка
```
npm install
npm run dev          # веб-версия в браузере
```

## Сборка APK
```
npm run apk          # vite build + cap sync + gradle assembleDebug
```
Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Обои на фон
Положи картинку-обои в `public/bg.jpg` и пересобери (`npm run apk`). Без файла
показывается мягкий градиент в тон темы. Фон затемняется автоматически, чтобы
карточки читались.

## Синхронизация между устройствами
Пока данные только на устройстве. При необходимости позже можно добавить Supabase
(как в BuildFlow) или экспорт/импорт JSON.
